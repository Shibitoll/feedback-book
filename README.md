# 📚 Книга відгуків

Вебдодаток для роботи з каталогом книг, який дає змогу переглядати інформацію про книги, залишати відгуки та керувати ними. Проєкт розроблено з використанням **Jakarta EE** та організовано у вигляді багатомодульної Maven-структури. Обробка HTTP-запитів здійснюється за допомогою сервлетів, а для зберігання даних використовується **H2 Database** через JDBC.

## 🛠 Технологічний стек

- **JDK:** 21
- **Maven:** 3.9.16
- **Вебсервер:** Jetty 11 (Servlet 5.0 / Jakarta EE 9+)
- **База даних:** H2 (вбудована, файловий режим)
- **Логування:** SLF4J + Logback
- **Тестування:** JUnit 5, ArchUnit
- **Архітектура:** багатомодульна структура з розділенням на Domain, Ports та Adapters.

---

## 📁 Структура проєкту

Проєкт складається з трьох модулів, кожен із яких відповідає за окрему частину функціональності. Такий підхід спрощує підтримку коду та забезпечує розмежування відповідальності.

```text
MPF_Labs/
├── pom.xml       # Головний Maven-файл із конфігурацією модулів
├── core/         # Доменні моделі, бізнес-правила та порти
│   └── src/main/java/sumdu/edu/ua/core/
├── persistence/  # Доступ до бази даних H2 та реалізація роботи з даними
│   └── src/main/java/sumdu/edu/ua/persistence/
└── web/          # Сервлети, фільтри, конфігурація та JSP-сторінки
    └── src/main/java/sumdu/edu/ua/web/
```

### Призначення модулів

- **`core`** — містить основні сутності предметної області, бізнес-логіку та інтерфейси взаємодії.
- **`persistence`** — відповідає за збереження, отримання та видалення даних у базі H2.
- **`web`** — забезпечує взаємодію з користувачем через HTTP, обробляє запити та формує вебсторінки.

## 📋 Бізнес-правила

### Обмеження на видалення відгуків

Видалення відгуку дозволяється лише протягом **24 годин після його створення**. Перевірка цього обмеження реалізована в `CommentService`.

## 🚀 Збірка та запуск

Усі команди необхідно виконувати з кореневої директорії проєкту `MPF_Labs`.

### 1. Збірка проєкту

Для очищення попередніх результатів збірки, компіляції модулів і встановлення артефактів у локальний Maven-репозиторій виконайте:

```bash
mvn clean install
```

### 2. Запуск вебдодатка

Для запуску вбудованого сервера Jetty використовуйте команду:

```bash
mvn -pl web jetty:run
```

Після запуску вебдодаток буде доступний за адресою:

**http://localhost:8080/books**

## 🧪 Архітектурні тести

Для автоматичного контролю структури застосунку використовується бібліотека **ArchUnit**. Вона дає змогу перевіряти залежності між модулями та дотримання встановлених архітектурних обмежень.

Основні правила перевірки:

- Сервлети розміщуються лише в модулі `web`.
- Модуль `web` не повинен напряму залежати від `persistence`, за винятком фабрики ініціалізації `Beans`.
- Модуль `core` залишається незалежним від модулів `web` і `persistence`.
- Модуль `persistence` не повинен залежати від `web`.

### Запуск тестів

Щоб виконати всі автоматизовані перевірки, запустіть у кореневій директорії проєкту:

```bash
mvn test
```

## 📝 Логування та обробка помилок

Для відстеження роботи застосунку та діагностики проблем використовується **SLF4J + Logback**.

### Рівні логування

- **`INFO`** — інформація про успішне створення та видалення відгуків із зазначенням основних атрибутів.
- **`WARN`** — попередження про помилки клієнтських запитів із кодами `4xx`, зокрема некоректні параметри або відсутні ресурси.
- **`ERROR`** — повідомлення про внутрішні помилки сервера з кодами `5xx` та повним стеком винятку.

### Обробка помилок

`ErrorFilter` перехоплює необроблені винятки та повертає клієнту відповідь у єдиному JSON-форматі:

```json
{
  "error": "Internal Server Error",
  "message": "деталі помилки"
}
```

## 🗄 База даних

Для зберігання інформації про книги та відгуки використовується вбудована СУБД **H2** у файловому режимі.

- **Тип бази даних:** H2 Database.
- **URL підключення:** `jdbc:h2:file:./data/guest;AUTO_SERVER=TRUE`
- **Файл бази даних:** `./data/guest.mv.db`

Файл бази даних створюється автоматично під час першого запуску, якщо він ще не існує.

## 📡 Список ендпоїнтів

### 🌐 Сторінки (HTML/JSP)

| Метод | URL | Призначення |
|---|---|---|
| `GET` | `/books` | Відображає каталог книг. Підтримує пошук за параметром `q` та пагінацію за допомогою параметрів `page` і `size`. |
| `GET` | `/comments?bookId={id}` | Відкриває сторінку конкретної книги зі списком відгуків і формою для додавання нового коментаря. |

### 🔌 API (сервлети)

#### 1. Додавання відгуку

**`POST /comments`**

Додає новий відгук до вибраної книги.

**Параметри форми:**

- `bookId` — ідентифікатор книги.
- `author` — ім'я автора відгуку.
- `text` — текст відгуку.

#### 2. Видалення відгуку

**`POST /comments`**

Видаляє відгук із перевіркою обмеження на видалення протягом 24 годин після створення.

**Параметри форми:**

- `bookId` — ідентифікатор книги.
- `commentId` — ідентифікатор відгуку.
- `_method=delete` — параметр, що вказує на операцію видалення.

#### 3. Отримання списку книг

**`GET /api/books`**

Повертає список книг у форматі JSON.

**Підтримувані параметри:**

- `page` — номер сторінки.
- `size` — кількість записів на сторінці.
- `q` — пошуковий запит для фільтрації книг.

#### 4. Створення книги

**`POST /api/books`**

Створює новий запис про книгу на основі JSON-запиту.

**Поля JSON-запиту:**

- `title` — назва книги.
- `author` — автор книги.
- `pubYear` — рік видання.
