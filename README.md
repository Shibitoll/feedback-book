# 📖 Книга відгуків

Вебдодаток на базі **Jakarta EE** для додавання та перегляду відгуків. Для обробки HTTP-запитів використовуються сервлети, а для збереження даних — вбудована база даних **H2**.

---

## 🛠 Технологічний стек

- **JDK:** 21
- **Maven:** 3.9.6 або актуальна версія
- **Java Enterprise:** Jakarta EE (Servlets)
- **Application Server:** Embedded Jetty Plugin
- **Database:** H2 Database Engine

---

## 🚀 Команди запуску

Для збірки та запуску вбудованого сервера Jetty виконайте в кореневій директорії проєкту такі команди:

```bash
mvn clean compile
mvn jetty:run
```

Після успішного запуску додаток буде доступний у браузері за адресою:

[**http://localhost:8080/**](http://localhost:8080/)

---

## 🗄 База даних

- **СУБД:** H2 (працює в локальному файловому режимі).
- **URL підключення:** `jdbc:h2:file:./data/guest;AUTO_SERVER=TRUE`
- **Шлях до файлу БД:** `./data/guest.mv.db` (створюється автоматично в корені проєкту під час першого запуску).

## 📡 Список ендпоїнтів

### 🌐 Сторінки

| Метод | URL | Опис |
|---|---|---|
| `GET` | `/` | Головна HTML-сторінка. Містить форму для надсилання відгуку (ім'я та текст) і динамічний список залишених коментарів. |

### 🔌 API (сервлети)

#### 1. Отримання коментарів

- **Метод:** `GET /comments`
- **Опис:** Повертає JSON-список усіх збережених відгуків, відсортованих від найновіших до найстаріших (останні зверху).
- **Коди відповідей:**
  - `200 OK` — запит успішно виконано.

#### 2. Додавання коментаря

- **Метод:** `POST /comments`
- **Опис:** Додає новий запис до бази даних. Тіло відповіді відсутнє.
- **Параметри (Form Data):**
  - `author` (обов'язково) — ім'я автора, максимум 64 символи.
  - `text` (обов'язково) — текст відгуку, максимум 1000 символів.
- **Коди відповідей:**
  - `204 No Content` — коментар успішно додано.
  - `400 Bad Request` — помилка валідації: відсутні обов'язкові поля або перевищено обмеження довжини.
  - `500 Internal Server Error` — помилка бази даних.
