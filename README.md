# 📚 Книга відгуків (Spring Boot MVC / Thymeleaf SSR & i18n)

Проєкт являє собою багатомодульний вебзастосунок, призначений для роботи з каталогом книг і відгуками користувачів. Його структура організована за допомогою Maven та включає три модулі: `core`, `persistence` і `web`, кожен із яких виконує окремі функції.

У цій версії реалізовано серверне формування вебсторінок (**SSR**) із використанням шаблонізатора **Thymeleaf**. Замість REST-контролерів, які повертали JSON, застосовуються MVC-контролери з анотацією `@Controller`. Вони передають необхідні дані до об'єкта `Model`, на основі якого генеруються HTML-сторінки. Також реалізовано зв'язування даних HTML-форм із Java-об'єктами та можливість перемикання мови інтерфейсу за допомогою механізму інтернаціоналізації (i18n).

## 🛠 Технологічний стек

- **JDK:** 21
- **Maven:** 3.9.16
- **Фреймворк:** Spring Boot 3.3.4 (`spring-boot-starter-web`, `spring-boot-starter-thymeleaf`)
- **Шаблонізатор:** Thymeleaf (HTML5 / SSR)
- **Вебсервер:** Вбудований Apache Tomcat (порт `8080`)
- **СУБД:** H2 (вбудована, файловий режим)
- **Тестування:** JUnit 5, ArchUnit
- **Архітектура:** багатомодульна структура з розділенням на Domain/Ports/Adapters.

## 📁 Структура проєкту

Для кращої організації коду застосунок поділено на три модулі, між якими розподілено відповідальність за бізнес-процеси, збереження інформації та взаємодію з користувачем.

```text
MPF_Labs/
├── pom.xml          # Батьківський POM для керування модулями та версіями
├── core/            # Доменні об'єкти, порти та сервіси бізнес-логіки (@Service)
│   └── src/main/java/sumdu/edu/ua/core/
├── persistence/     # Реалізація взаємодії з базою даних H2 (@Repository)
│   └── src/main/java/sumdu/edu/ua/persistence/
└── web/             # MVC-контролери, Thymeleaf-шаблони та конфігурація i18n
    ├── src/main/java/sumdu/edu/ua/
    │   ├── config/
    │   │   ├── LanguageConfig.java   # Налаштування локалізації та перемикання мов
    │   │   └── WebConfig.java        # Конфігурація Spring MVC та статичних ресурсів
    │   └── web/
    │       ├── AppInit.java          # Головний клас запуску Spring Boot
    │       └── controller/
    │           ├── BooksController.java     # Обробка запитів каталогу книг
    │           └── CommentsController.java  # Обробка операцій із коментарями
    └── src/main/resources/
        ├── application.properties    # Основні параметри застосунку
        ├── messages.properties       # Текстові ресурси (українська мова)
        ├── messages_en.properties    # Текстові ресурси (англійська мова)
        ├── messages_fr.properties    # Текстові ресурси (французька мова)
        └── templates/
            ├── books.html            # Сторінка каталогу
            ├── book-form.html        # Форма створення книги
            ├── book-comments.html    # Сторінка відгуків до книги
            └── fragments/
                └── header.html       # Спільна шапка та навігаційне меню
```

### Призначення модулів

- **`core`** — містить основні сутності предметної області, інтерфейси та сервіси, у яких зосереджено бізнес-правила.
- **`persistence`** — відповідає за доступ до H2 та виконання операцій із даними відповідно до визначених портів.
- **`web`** — забезпечує роботу MVC-контролерів, обробку користувацьких запитів, відображення Thymeleaf-шаблонів і налаштування багатомовного інтерфейсу.

## ⚙️ Архітектура Spring MVC, Thymeleaf та i18n

Вебрівень використовує модель **Spring MVC**, доповнену серверною генерацією HTML за допомогою Thymeleaf та засобами локалізації інтерфейсу.

### Серверне формування сторінок (SSR)

MVC-контролери обробляють запити, готують необхідні дані та додають їх до об'єкта `Model`. Після цього повертається назва відповідного шаблону, наприклад `return "books"`. За формування готової HTML-сторінки на основі переданих даних відповідає `ThymeleafViewResolver`.

### Зв'язування даних форм (Form Binding)

Для передачі інформації з HTML-форми до Java-об'єктів використовується механізм зв'язування Thymeleaf.

У шаблоні `book-form.html` застосовуються атрибути:

- `th:object="${bookForm}"` — визначає об'єкт, із яким пов'язана форма.
- `th:field="*{fieldName}"` — встановлює зв'язок між окремими полями форми та властивостями Java-об'єкта `Book`.

Це дозволяє автоматизувати перенесення введених користувачем значень до відповідного об'єкта.

### Локалізація та мультимовність (i18n)

Для підтримки кількох мов використовується вбудований механізм локалізації Spring.

- **`CookieLocaleResolver`** — зберігає вибрану користувачем мову в cookie з назвою `lang`. Початковою мовою інтерфейсу є українська (`uk`).
- **`LocaleChangeInterceptor`** — обробляє параметр `?lang=` в URL і дозволяє перемикати мову, наприклад `/books?lang=en`.
- **Resource Bundles** — містять текстові значення для різних мов у файлах `messages.properties`, `messages_en.properties` та `messages_fr.properties`.
- **`th:text="#{key}"`** — використовується в Thymeleaf для відображення тексту відповідно до поточної локалі.

### Повторне використання елементів сторінок (Layout Fragments)

Спільні частини інтерфейсу винесені в окремі фрагменти, щоб не дублювати однакову розмітку на різних сторінках.

Наприклад, заголовок і навігаційне меню знаходяться у файлі `fragments/header.html` та підключаються до інших шаблонів за допомогою:

```html
th:replace="~{fragments/header :: header}"
```

## 📋 Бізнес-правила

Під час роботи застосунку враховуються додаткові умови, які визначають поведінку сторінок і доступні користувачам операції.

- **Відображення порожніх списків:** якщо каталог не містить книг або для вибраної книги ще немає відгуків, Thymeleaf використовує `th:if` та `th:unless` для показу відповідних повідомлень: «Немає книг.» або «Коментарів поки немає.».
- **Обмеження на видалення відгуків:** видалити коментар дозволяється лише протягом 24 годин після його створення. Перевірка цього правила реалізована в класі `CommentService` модуля `core`.

## 🚀 Збірка та запуск

Усі команди для компіляції та збірки виконуються з кореневої директорії проєкту `MPF_Labs`. Запуск самого вебзастосунку відбувається через модуль `web`.

### 1. Повна збірка проєкту та виконання тестів

Для очищення попередніх результатів збірки, компіляції модулів і виконання тестів скористайтеся командою:

```bash
mvn clean install
```

### 2. Запуск Spring Boot

Запустити застосунок можна одним із двох способів.

**Через Maven CLI:**

```bash
mvn spring-boot:run -pl web
```

**Через IDE:**

Запустіть метод `main()` у класі `AppInit.java`, який розташований за шляхом:

`web/src/main/java/sumdu/edu/ua/web/AppInit.java`

Після успішного запуску головна сторінка застосунку буде доступна за адресою:

**http://localhost:8080/books**

## 🧪 Архітектурні тести (ArchUnit)

Для контролю правильності побудови модулів та їхніх залежностей використовується бібліотека **ArchUnit**. Вона дає змогу автоматично перевіряти архітектурні обмеження та виявляти небажані зв'язки між окремими частинами застосунку.

Основні правила перевірки:

- Модуль `core` повинен бути незалежним від `web` та `persistence`.
- Між модулями `web` і `persistence` не допускаються прямі залежності, за винятком передбачених конфігураційних компонентів Spring IoC.

### Запуск тестів

Для виконання всіх автоматизованих тестів із кореня проєкту потрібно виконати:

```bash
mvn test
```

## 🌐 Доступні вебсторінки та маршрути

Взаємодія з користувачем відбувається через HTML-сторінки, які формуються на сервері за допомогою Thymeleaf. Обробку маршрутів забезпечують MVC-контролери.

### 📚 Маршрути каталогу книг (`BooksController`)

| Метод | URL | Призначення |
|---|---|---|
| `GET` | `/books` | Відкриває каталог книг на основі шаблону `books.html`. Підтримує перемикання мови через параметри `?lang=en` та `?lang=fr`. |
| `GET` | `/books/add` | Відображає форму створення нової книги за допомогою `book-form.html`. |
| `POST` | `/books` | Приймає дані заповненої форми, створює нову книгу та перенаправляє користувача на `/books`. |

### 💬 Маршрути коментарів (`CommentsController`)

| Метод | URL | Призначення |
|---|---|---|
| `GET` | `/comments?bookId={id}` | Відкриває сторінку `book-comments.html` зі списком відгуків до вибраної книги. |
| `POST` | `/comments` | Обробляє форму створення нового коментаря та після успішного виконання перенаправляє на `/comments?bookId={id}`. |
| `POST` | `/comments/delete` | Виконує видалення коментаря за параметрами `commentId` та `bookId` з подальшим перенаправленням на сторінку відгуків відповідної книги. |
