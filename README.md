# 📚 Книга відгуків (Spring Boot)

Вебдодаток призначений для роботи з каталогом книг та відгуками користувачів. Проєкт має модульну структуру Maven і складається з трьох частин: `core`, `persistence` та `web`, кожна з яких відповідає за окремий напрям роботи системи.

У цій версії для організації вебрівня використовується **Spring Boot**, який забезпечує автоматичне налаштування застосунку та керування його компонентами. Взаємодія з вебклієнтом реалізована за допомогою Jakarta Servlets, зареєстрованих у Spring через `ServletRegistrationBean`. Для обробки даних використовується Jackson, а їх зберігання забезпечує вбудована база даних H2 через JDBC.

## 🛠 Технологічний стек

- **JDK:** 21
- **Maven:** 3.9.16
- **Фреймворк:** Spring Boot 3.3.4 (`spring-boot-starter`, `spring-boot-starter-web`)
- **Вебсервер:** Вбудований Apache Tomcat
- **JSON:** Jackson (інтегрований у Spring Boot Web)
- **СУБД:** H2 (вбудована, файловий режим)
- **Тестування:** JUnit 5, ArchUnit
- **Архітектура:** багатомодульна організація Domain/Ports/Adapters.

## 📁 Структура проєкту

Для розмежування функціональності застосунок поділено на три модулі. Кожен із них має власну зону відповідальності, що спрощує супровід і подальше розширення проєкту.

```text
MPF_Labs/
├── pom.xml          # Батьківська конфігурація Maven та керування модулями
├── core/            # Доменні сутності, порти та сервіси бізнес-логіки
│   └── src/main/java/sumdu/edu/ua/core/
├── persistence/     # Робота з H2 та реалізація доступу до даних
│   └── src/main/java/sumdu/edu/ua/persistence/
└── web/             # Spring Boot, конфігурація, сервлети та статичний інтерфейс
    ├── src/main/java/sumdu/edu/ua/web/
    └── src/main/resources/application.properties
```

### Призначення модулів

- **`core`** — центральна частина системи, що містить доменні моделі, бізнес-правила, сервіси та інтерфейси (порти).
- **`persistence`** — реалізує взаємодію зі сховищем даних, зокрема операції читання та запису в H2.
- **`web`** — відповідає за запуск Spring Boot, реєстрацію сервлетів, обробку HTTP-запитів та роботу клієнтського інтерфейсу.

## ⚙️ Конфігурація та IoC/DI

Для керування компонентами та їх взаємодією застосовується механізм IoC/DI, який надає Spring Boot.

Основні елементи конфігурації:

- **`AppInit.java`** — головний клас застосунку з анотацією `@SpringBootApplication`, з якого починається запуск системи.
- **`ServletConfig.java`** — клас конфігурації з анотацією `@Configuration`, у якому налаштовується реєстрація сервлетів.
- **`ServletRegistrationBean`** — використовується для додавання `BooksServlet` та `CommentsServlet` до контейнера Spring через методи з анотацією `@Bean`.
- **`applicationName`** — додатковий користувацький Spring-бін, створений у конфігурації.
- **Constructor Injection** — передавання необхідних сервісів і репозиторіїв через конструктори класів.

### Файл налаштувань

У `application.properties` задаються основні параметри роботи застосунку, зокрема:

```properties
server.port=8080
```

Цей параметр визначає порт, на якому запускається вбудований вебсервер. Інші налаштування використовуються для конфігурації вебсередовища та автоматичного налаштування Spring Boot.

## 📋 Бізнес-правила

### Обмеження на видалення відгуків

Система передбачає обмеження на видалення коментарів: користувач може видалити власний відгук лише протягом **24 годин після його створення**.

Відповідна перевірка реалізована в класі `CommentService` модуля `core`. Розміщення правила на рівні бізнес-логіки забезпечує його незалежність від вебінтерфейсу та механізму зберігання даних.

## 🚀 Збірка та запуск

Збірку проєкту необхідно виконувати з його кореневої директорії `MPF_Labs`, а запуск вебзастосунку здійснюється через модуль `web`.

### 1. Збірка проєкту та виконання тестів

Для очищення попередніх результатів компіляції, збирання всіх модулів і виконання тестів використовується команда:

```bash
mvn clean install
```

### 2. Запуск Spring Boot

Для запуску застосунку через Maven виконайте:

```bash
mvn spring-boot:run -pl web
```

Також доступний альтернативний спосіб запуску через IDE: необхідно виконати метод `main()` у класі `AppInit.java`, розташованому за шляхом:

`web/src/main/java/sumdu/edu/ua/web/AppInit.java`

Після успішного запуску вебклієнт буде доступний за адресою:

**http://localhost:8080/**

## 🧪 Архітектурні тести (ArchUnit)

Для перевірки правильності побудови архітектури використовується бібліотека **ArchUnit**. Вона дозволяє автоматично контролювати залежності між модулями та запобігати порушенню встановленої структури застосунку.

Основні архітектурні обмеження:

- Модуль `core` не повинен залежати від інших шарів — `web` та `persistence`.
- Модуль `web` не повинен мати прямих залежностей від `persistence`, окрім конфігураційних компонентів Spring IoC.
- Залежності між компонентами мають відповідати визначеному розподілу відповідальності.

### Запуск тестів

Для виконання автоматизованих перевірок з кореневої директорії проєкту потрібно запустити:

```bash
mvn test
```

## 🗄 База даних

Для збереження відомостей про книги та відгуки використовується **H2 Database**. База працює у файловому режимі, тому дані зберігаються локально та залишаються доступними після завершення роботи застосунку.

- **Тип СУБД:** H2 Database.
- **URL підключення:** `jdbc:h2:file:./data/guest;AUTO_SERVER=TRUE`
- **Розташування файлу БД:** `./data/guest.mv.db`

Файл бази даних створюється автоматично під час першого запуску, якщо він ще не існує.

## 📡 Список доступних URL та ендпоїнтів

### 🌐 Клієнтський інтерфейс

| Метод | URL | Призначення |
|---|---|---|
| `GET` | `/` | Відкриває головну сторінку або перенаправляє на статичний файл `index.html`. |
| `GET` | `/index.html` | Відображає HTML-інтерфейс із JavaScript для перегляду каталогу книг та роботи з відгуками. |

### 📚 API книг (`BooksServlet`)

#### 1. Отримання переліку книг

**`GET /books`**

Повертає список доступних книг у форматі JSON.

#### 2. Отримання інформації про книгу

**`GET /books/{id}`**

Надає інформацію про конкретну книгу за її ідентифікатором `id`.

### 💬 API коментарів (`CommentsServlet`)

#### 1. Отримання списку відгуків

**`GET /comments`**

Повертає перелік збережених відгуків у форматі JSON за допомогою `CommentsServlet`.

#### 2. Додавання відгуку

**`POST /comments`**

Дозволяє створити новий коментар до книги. Запит обробляється сервлетом `CommentsServlet`.
